# Design reference

Approved reference: `docs/design/reference.webp` (warm Mediterranean-kitchen editorial: cream/oat, terracotta, sage, saffron, serif display + clean sans).

## Implemented in Phase 1

- Desktop: illustrated left rail (logo, 9 nav items, theme toggle), top bar (search, bell, date, avatar), hero greeting, "Cook with what you have" card + filter chips, storage scene with Pantry/Fridge/Freezer tabs, expiring panel, week strip, quote card.
- Mobile: logo + bell header, bottom nav (Home, Pantry, Recipes, Planner, More), back button on every sub-page, safe-area padding, ≥44px targets.

## Known differences from the reference (intentional)

- **No photography.** Original SVG illustrations instead. Recipe cards/photos land in Phase 3.
- **Empty states instead of sample numbers** (24 ingredients, tomatoes in 2 days…). Real counts come from the database.
- **Storage scene is simple empty shelves** in Phase 1; the jar-filled interactive Living Pantry is Phase 2 and must reflect logged stock only.
- **No EN/MK switch** (English only by decision). Theme toggle sits in that slot.
- Mobile screens beyond Home/Pantry/More/Settings are empty states until their phases.
